# Legally Blonde 

## About the Movie

**Legally Blonde** is a 2001 comedy starring *Reese Witherspoon* as **Elle Woods**, a fashion-loving sorority president who follows her ex to Harvard Law School and proves she's far more capable than anyone expects.

> "What, like it's hard?" – Elle Woods
